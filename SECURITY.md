# Security and data handling

This project starts as a static website; it accepts no accounts, uploads or secrets and stores no visitor data. It is not a service for controlled-access astronaut, clinical, or otherwise sensitive individual-level data.

Do not commit passwords, API tokens, confidential reviewer correspondence, unpublished manuscripts you are not permitted to share, or controlled-access data. If credentials are introduced later, use environment secrets and private deployment settings.

For security issues, open a private GitHub security advisory after enabling private vulnerability reporting for the repository. Do not publish exploit details in a public issue.
