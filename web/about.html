Map the evidence across space biology.

Spaceflight Biology Navigator brings together NASA OSDR study records and publication metadata, then organizes them into public research topics. Its long-term purpose is to make evidence-backed findings, unresolved questions, and candidate datasets easier to discover.

What this release covers

Loading the bundled Biological Data API snapshot details…

The homepage opens with a candidate research question for each of the nine topic lenses and a short list of OSDR records selected through topic metadata. Source context is provided where available. These are analyst-inferred screening hypotheses, not claims that a question is novel or remains unresolved. Dataset leads are ordered by metadata completeness, not scientific suitability, and have not passed sample-level feasibility review.

A second homepage mode shows the full snapshot as a network of overlapping metadata topic matches. The separate Brain evidence graph contains curated study-level links; it is not exhaustive coverage of every subject area.

The API snapshot contains one aggregate dataset record per accession. A publication title appearing in NASA metadata is a screening lead; it does not prove that the publication used every assay or sample in the accession.

How to use the visual research map

Start with Gap hypotheses & dataset leads. The central field connects to topic question nodes, and dashed links connect each question to three displayed OSDR dataset leads selected through topic metadata. Select a question node to read the full hypothesis and lead list, or select a dataset node to inspect its metadata and NASA source page. Dashed links indicate a metadata match; they do not establish that a record can answer the question. Switch to Topic metadata network to inspect all dataset records and shared topic matches. This remains a screening map, not a completed publication inventory or expert-reviewed gap map.

How to read the curated Brain gap map

  • Mint study cards summarize a reported finding and an open question.
  • Lavender study cards identify later analyses linked to earlier work.
  • Blue dataset nodes and solid teal edges denote documented dataset use, with evidence notes in the study panel.
  • Orange-outlined dataset nodes and dashed orange edges are candidate datasets for a question, not validated experiments.
  • Purple arrows show documented relationships between later papers and earlier questions.
  • Pastel background clusters indicate research themes, not quality or strength of evidence.

Sources and boundaries

The bundled snapshot covers the NASA OSDR Biological Data API, which indexes GeneLab and ALSDA. OSDR also exposes separate services for environmental telemetry, radiation data, biospecimens, microbial cultures, and other data; those sources need dedicated ingestion and coverage work.
